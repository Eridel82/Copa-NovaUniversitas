# ⚽ Torneo Universitario

Página web desarrollada para el **torneo deportivo realizado en la universidad**, con el propósito de centralizar y mostrar de manera organizada la información de los equipos, partidos y resultados de la competencia.

> 🚧 **Proyecto académico / universitario**

---

## 🎯 Objetivo

Desarrollar una página web que permita a los participantes y estudiantes consultar fácilmente la información relacionada con el torneo.

La plataforma busca mejorar la organización y presentación de los datos, ofreciendo un espacio donde los usuarios puedan conocer el desarrollo de la competencia.

---

## ✨ Características

La página incluye diferentes apartados relacionados con el torneo:

* ⚽ Información general del torneo.
* 👥 Equipos participantes.
* 📅 Calendario de partidos.
* 🏆 Resultados.
* 📊 Tabla de posiciones.
* ⚽ Información de encuentros.
* 🥇 Equipos destacados.
* 📰 Noticias o información del torneo.
* 📱 Diseño adaptable a diferentes dispositivos.

---

## 🏆 Información del torneo

Los participantes pueden consultar información como:

* Nombre del torneo.
* Equipos participantes.
* Jornadas.
* Fechas y horarios.
* Resultados de los partidos.
* Puntos obtenidos.
* Posición de cada equipo.
* Partidos jugados, ganados, empatados y perdidos.

---

## ⚽ Partidos

Cada encuentro puede mostrar información como:

```text
Equipo A          3 - 2          Equipo B

📅 Fecha
⏰ Hora
📍 Lugar
🏆 Jornada
```

Esto permite que los participantes puedan consultar rápidamente los detalles de cada partido.

## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Entrar al proyecto

```bash
cd torneo-universitario
```

### 3. Ejecutar

Si se trata de un proyecto web estático, puede abrirse directamente el archivo:

```text
index.html
```

También puede ejecutarse utilizando una extensión como **Live Server** en Visual Studio Code.
